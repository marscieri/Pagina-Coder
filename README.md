# Taylor Swift Fan Page

Fan page de Taylor Swift. Proyecto final del curso de desarrollo web.

## Estructura de archivos

```
taylor-swift/
├── index.html              ← Página principal
├── css/
│   └── style.css           ← Todos los estilos
├── scss/                   ← (Para cuando instales Node + SASS)
├── img/
│   ├── hero_bg.jpg         ← Imagen de fondo del hero
│   ├── taylor_home.jpg     ← Foto en la página home
│   ├── icons/
│   │   ├── instagram.png
│   │   ├── youtube.png
│   │   └── facebook.png
│   ├── albums/             ← (No se usan, los albums usan Spotify embed)
│   └── gallery/
│       ├── foto1.jpg
│       ├── foto2.jpg
│       └── ...
└── page/
    ├── tour.html
    ├── discografia.html
    ├── galeria.html
    └── contacto.html
```

## Tecnologías usadas

- HTML5 semántico
- CSS3 con variables y animaciones
- Bootstrap 5.3
- Spotify Embeds

## Cómo correrlo

Abrí el archivo `index.html` en el navegador.
